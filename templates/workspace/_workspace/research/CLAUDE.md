# _workspace/research/

Open questions evaluating options before committing to a direction. One file per question.

Each research doc should:

- State the question clearly at the top.
- List the options being considered.
- Compare them honestly — tradeoffs, costs, complexity.
- End with a recommendation *or* explicitly note "still open" if you haven't decided.

Once a research doc lands on a direction, promote it to a `planning/<feature>/` folder. Move the research file to `archived/` so the trail is preserved.

If a research question is answered but doesn't lead to immediate work ("we evaluated X and decided not to do anything yet"), leave the doc in `research/` and mark it `Resolved: no action`.
