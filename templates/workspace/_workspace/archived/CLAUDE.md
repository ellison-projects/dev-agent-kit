# _workspace/archived/

Finished plans, abandoned research, original launch material. The retention folder.

Move things here when:

- A `planning/<feature>/` folder is shipped and promoted to `docs/systems/`. Keep the plan as a historical record.
- A `research/<question>.md` led to a decision and isn't the active question anymore.
- An old document is no longer accurate but worth keeping for context.

Files in `archived/` are read-only in spirit. Don't update them — they capture a moment in time. If you need to revise the thinking, write a new doc in the appropriate live folder.
