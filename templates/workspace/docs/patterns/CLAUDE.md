# docs/patterns/

Code conventions you want enforced everywhere. One file per convention.

Each pattern doc should answer:

- **What is the convention?** A clear, scannable rule ("use X helper, not direct calls").
- **Why?** What problem does the convention solve.
- **Where does it apply?** Scope the rule to a folder, file pattern, or scenario.
- **How do I follow it?** Minimal example code.

Reference patterns from the top-level `CLAUDE.md` (or a folder-scoped CLAUDE.md) so agents discover them in context. A pattern doc nobody links to is invisible.
